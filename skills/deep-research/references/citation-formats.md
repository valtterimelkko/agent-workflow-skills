# Citation Formats Reference

Standard citation formats for different source types in research reports.

## APA 7th Edition (Most Common)

### Journal Article
```
Author, A. A., & Author, B. B. (Year). Title of article. Title of Periodical, volume(issue), page range. https://doi.org/xxxxx
```

Example:
```
Smith, J. D., & Jones, M. R. (2023). Machine learning approaches to climate prediction. Nature Climate Science, 15(3), 234-256. https://doi.org/10.1038/s41558-023-01678-9
```

### Website
```
Author, A. A. (Year, Month Day). Title of page. Site Name. URL
```

Example:
```
Johnson, K. L. (2024, January 15). The future of renewable energy. TechCrunch. https://techcrunch.com/2024/01/15/renewable-energy-future
```

### Online News Article
```
Author, A. A. (Year, Month Day). Title of article. Publication Name. URL
```

Example:
```
Chen, W. (2024, March 10). New AI model achieves breakthrough in medical diagnosis. The New York Times. https://www.nytimes.com/2024/03/10/technology/ai-medical-diagnosis.html
```

### Blog Post
```
Author, A. A. (Year, Month Day). Title of blog post. Blog Name. URL
```

Example:
```
Andreessen, M. (2024, February 1). Why AI will save the world. Marc Andreessen's Blog. https://pmarchive.com/ai-will-save-the-world
```

### Report/Whitepaper
```
Organization Name. (Year). Title of report (Report No. xxx). Publisher. URL
```

Example:
```
McKinsey & Company. (2024). The state of AI in 2024. https://www.mckinsey.com/capabilities/quantumblack/our-insights/the-state-of-ai-in-2024
```

### Conference Paper
```
Author, A. A. (Year, Month Day-Day). Title of paper. In Name of Conference. Publisher. URL
```

Example:
```
Brown, T., et al. (2023, December 10-16). Language models are few-shot learners. In Advances in Neural Information Processing Systems 33. NeurIPS. https://proceedings.neurips.cc/paper/2020
```

## IEEE Format (Technical Papers)

### Journal Article
```
[1] A. A. Author and B. B. Author, "Title of article," Title of Journal, vol. x, no. x, pp. xxx-xxx, Month Year.
```

Example:
```
[1] J. Smith and M. Jones, "Deep learning for image recognition," IEEE Transactions on Pattern Analysis and Machine Intelligence, vol. 45, no. 6, pp. 1234-1248, June 2023.
```

### Website
```
[1] "Title of page," Website Name. URL (accessed Month Day, Year).
```

Example:
```
[1] "PyTorch documentation," PyTorch. https://pytorch.org/docs/stable/index.html (accessed Jan. 15, 2024).
```

## Chicago Style (Books and Humanities)

### Book
```
Author First Last, Title of Book (Place of Publication: Publisher, Year), page range.
```

Example:
```
Nick Bostrom, Superintelligence: Paths, Dangers, Strategies (Oxford: Oxford University Press, 2014), 45-67.
```

### Website (Footnote)
```
Author First Last, "Title of Page," Website Name, Publication Date or Modified Date, URL.
```

Example:
```
Tim Urban, "The AI Revolution: The Road to Superintelligence," Wait But Why, January 22, 2015, https://waitbutwhy.com/2015/01/artificial-intelligence-revolution-1.html.
```

## MLA 9th Edition (Humanities)

### Website
```
Author Last, First. "Title of Page." Website Name, Publisher, Date, URL.
```

Example:
```
Harari, Yuval. "The Rise of the Useless Class." The Guardian, Guardian News and Media, 24 May 2017, www.theguardian.com/technology/2017/may/24/the-rise-of-the-useless-class-ai-artificial-intelligence.
```

## Harvard Referencing

### Website
```
Author, Initial(s). (Year) 'Title of page', Website Name, Available at: URL (Accessed: Day Month Year).
```

Example:
```
Smith, J. (2024) 'The impact of artificial intelligence on employment', Harvard Business Review, Available at: https://hbr.org/2024/01/ai-employment-impact (Accessed: 15 March 2024).
```

## Source-Specific Formats

### GitHub Repository
```
Author/Organization. (Year). Repository Name [Computer software]. GitHub. URL
```

Example:
```
OpenAI. (2024). GPT-4 [Computer software]. GitHub. https://github.com/openai/gpt-4
```

### YouTube Video
```
Creator. (Year, Month Day). Title of video [Video]. YouTube. URL
```

Example:
```
3Blue1Brown. (2023, June 15). But what is a neural network? [Video]. YouTube. https://www.youtube.com/watch?v=aircAruvnKk
```

### Podcast Episode
```
Host, A. A. (Host). (Year, Month Day). Title of episode (No. xxx) [Audio podcast episode]. In Podcast Name. Publisher. URL
```

Example:
```
Fridman, L. (Host). (2024, January 10). Elon Musk: Neuralink and the future of AI (No. 400) [Audio podcast episode]. In The Lex Fridman Podcast. https://lexfridman.com/podcast
```

### Government Document
```
Government Agency. (Year). Title of document (Document ID). Publisher. URL
```

Example:
```
National Institute of Standards and Technology. (2024). Artificial intelligence risk management framework (NIST AI 100-1). U.S. Department of Commerce. https://www.nist.gov/itl/ai-risk-management-framework
```

### Press Release
```
Organization. (Year, Month Day). Title of press release [Press release]. URL
```

Example:
```
OpenAI. (2024, February 15). OpenAI announces GPT-5 [Press release]. https://openai.com/blog/gpt-5-announcement
```

### Social Media Post
```
Author. [@username]. (Year, Month Day). Content of post [Tweet/Post]. Platform. URL
```

Example:
```
Musk, E. [@elonmusk]. (2024, March 1). Excited to announce our new AI breakthrough [Tweet]. Twitter. https://twitter.com/elonmusk/status/1234567890
```

### Email/Personal Communication
```
Sender, A. A. (Year, Month Day). Subject line [Personal communication].
```

Example:
```
Smith, J. D. (2024, January 10). Re: Research collaboration inquiry [Personal communication].
```

## Inline Citation Formats

### Parenthetical (APA Style)
```
Recent studies have shown significant progress (Smith & Jones, 2023).
```

### Narrative
```
Smith and Jones (2023) found significant progress in this area.
```

### Multiple Sources
```
Several studies support this finding (Brown, 2022; Chen, 2023; Davis, 2024).
```

### Direct Quote
```
As Smith (2023) noted, "The results were unexpected" (p. 45).
```

## Citation Management Tips

1. **Be Consistent**: Choose one format and use it throughout
2. **Include Access Dates**: For online sources, note when accessed
3. **Archive URLs**: Use Wayback Machine for sources that might disappear
4. **Verify DOIs**: Ensure DOI links work before finalizing
5. **Check Author Names**: Use full names when available, consistent initials
6. **Document as You Go**: Don't wait until the end to compile citations

## Citation Tools

- **Zotero**: Free, open-source reference manager
- **Mendeley**: Free with premium features
- **EndNote**: Commercial, institutional access common
- **Paperpile**: Subscription-based, integrates with Google Docs

## Quick Decision Tree

```
What type of source?
├── Academic/Scientific → APA
├── Technical/Engineering → IEEE
├── Humanities/History → Chicago
├── General web sources → APA or MLA
└── Mixed disciplines → APA (most versatile)
```

## Common Mistakes to Avoid

1. **Missing information**: Always include author, date, title, source
2. **Inconsistent formatting**: Stick to one style
3. **Broken links**: Verify URLs before submission
4. **Missing page numbers**: For direct quotes, always include
5. **Wrong date**: Use publication date, not access date (for most styles)
6. **Unclear author**: Use organization name if individual author unknown
7. **Typos in titles**: Copy-paste titles to avoid errors
