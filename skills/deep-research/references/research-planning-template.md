## Research Wave Planning

### Wave 1: Discovery
**Goal**: Cast wide net, understand landscape

**Agents to Spawn**:
- [ ] Academic/Technical Source Agent
- [ ] Industry/Practitioner Source Agent
- [ ] News/Current Events Agent
- [ ] Official/Government Source Agent
- [ ] Community/Discussion Agent

**Success Criteria**:
- Minimum 40-50 sources discovered
- Coverage of all dimensions
- Initial gap identification

### Wave 2: Deep Dive
**Goal**: Investigate gaps, verify sources, resolve contradictions

**Conditional**: Spawn based on Wave 1 findings

**Potential Agents**:
- [ ] Gap Analysis Agent
- [ ] Source Verification Agent
- [ ] Contradiction Resolution Agent
- [ ] Expert Synthesis Agent

**Success Criteria**:
- Key gaps filled
- Sources verified
- Contradictions resolved or explained

### Wave 3: Synthesis (Always Spawn)
**Goal**: Transform findings into coherent report

**Agents to Spawn**:
- [ ] Theme Extraction Agent
- [ ] Argument Construction Agent
- [ ] Citation Mapping Agent

### Wave 4: Quality Assurance (Always Spawn)
**Goal**: Verify accuracy and completeness

**Agents to Spawn**:
- [ ] Fact-Checking Agent
- [ ] Coverage Assessment Agent

## Risk Assessment

### Potential Challenges
| Challenge | Likelihood | Impact | Mitigation |
|-----------|------------|--------|------------|
| Limited sources on niche topic | Medium | High | Expand search terms, look for related topics |
| Contradictory information | High | Medium | Document both sides, find authoritative resolution |
| Time constraints | Medium | High | Prioritize high-impact sources, scope reduction |
| Source credibility issues | Medium | High | Use verification agents, find corroborating sources |

### Fallback Strategies
- If sources limited: Expand to related topics, include more expert opinions
- If contradictions persist: Present multiple viewpoints with analysis
- If behind schedule: Prioritize core dimensions, mark others as "future research"

## Example Completed Plan

### Research Question
"What are the current approaches to AI alignment, and what are their strengths and limitations?"

### Dimensions
1. **Technical Approaches** (RLHF, Constitutional AI, etc.)
2. **Theoretical Frameworks** (Debate, IRL, etc.)
3. **Practical Implementations** (Current systems)
4. **Criticism and Limitations** (Expert concerns)
5. **Future Directions** (Research agendas)

### Source Targets
- Academic papers on alignment: 20
- Industry technical reports: 10
- Expert opinion pieces: 10
- Criticism/debate sources: 10
- News on recent developments: 5

### Wave Planning
- Wave 1: 5 discovery agents (one per dimension)
- Wave 2: Gap analysis + contradiction resolution
- Wave 3: Synthesis agents
- Wave 4: QA verification

## Pre-Research Checklist

Before starting research:
- [ ] Research question is clear and specific
- [ ] Dimensions are well-defined
- [ ] Source requirements are realistic
- [ ] Timeline is appropriate
- [ ] Success criteria are measurable
- [ ] Fallback strategies are identified

## Post-Wave Checklist

After each wave:
- [ ] Agent outputs reviewed
- [ ] Sources catalogued
- [ ] Findings synthesized
- [ ] Gaps identified
- [ ] Next wave planned
- [ ] Progress logged
