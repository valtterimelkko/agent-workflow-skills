# Thematic Analysis Worksheets and Templates

## Phase 1: Familiarization Worksheet

### Document Summary Template

```
DOCUMENT: [Filename/Source]
DATE ANALYZED: [Date]

SUMMARY (2-3 sentences):
[Key content summary]

INITIAL OBSERVATIONS:
- [Pattern noticed]
- [Surprising element]
- [Connection to other documents]

QUESTIONS RAISED:
- [Question about data]
- [Area needing clarification]

REFLEXIVE NOTES:
My assumptions about this topic:
[Document biases/expectations]

Emotional reactions:
[Note any strong responses]
```

### Researcher Positionality Statement Template

```
RESEARCHER POSITIONALITY

Background and experience with topic:
[Your relationship to the research subject]

Pre-existing assumptions/hypotheses:
[What you expect to find]

Potential biases:
[How your position might shape interpretation]

Why this topic matters to you:
[Personal/professional investment]

Strategies for managing positionality:
[How you'll maintain reflexivity]
```

## Quality Checklist

### Pre-Analysis

- [ ] Research questions clearly defined
- [ ] Positionality statement written
- [ ] Data organized and accessible
- [ ] Transcription quality checked

### During Analysis

- [ ] All data given equal attention
- [ ] Coding systematic across dataset
- [ ] Codebook maintained and updated
- [ ] Memos written throughout
- [ ] Audit trail documented

### Post-Analysis

- [ ] Themes checked against full dataset
- [ ] Themes internally coherent
- [ ] Themes externally distinct
- [ ] Supporting quotes selected
- [ ] Analysis goes beyond description
- [ ] Research questions addressed
- [ ] Reflexivity evident

## Quick Reference: Code Types

| Type | Description | When to Use |
|------|-------------|-------------|
| **Descriptive** | Labels surface content | Initial organization |
| **Interpretive** | Captures underlying meaning | Deeper analysis |
| **In Vivo** | Uses participant words | Preserving voice |
| **Process** | Uses gerunds (-ing) | Studying actions/change |
| **Values** | Identifies beliefs | Understanding motivations |
| **Emotion** | Labels affective content | Capturing feelings |

## Quick Reference: Theme Quality

| Weak Theme | Strong Theme |
|------------|--------------|
| Topic summary | Central organizing concept |
| Descriptive only | Interpretive depth |
| Vague boundaries | Clear scope |
| Few quotes | Rich evidence |
| Generic name | Evocative name |
| Example: "Problems" | Example: "Navigating systemic neglect" |
