# Thematic Analysis Scenarios and Approaches

## Scenario 1: Single Researcher, Small Dataset (5-10 interviews)

### Recommended Approach: Reflexive Thematic Analysis

**Characteristics:**
- Personal interpretation central to analysis
- Organic code development
- No inter-rater reliability needed
- Flexibility prioritized

**Workflow:**
1. Read all transcripts 2-3 times (familiarization)
2. Create personal codebook as you go
3. Generate 50-80 initial codes
4. Cluster into 4-6 candidate themes
5. Review and refine iteratively
6. Write evocative theme definitions

**Time estimate:** 2-3 weeks

**Tools:**
- Word processor or note-taking app
- Spreadsheet for code tracking
- Physical or digital sticky notes for theme mapping

---

## Scenario 2: Research Team, Large Dataset (30+ interviews)

### Recommended Approach: Codebook Thematic Analysis

**Characteristics:**
- Shared codebook for consistency
- Some flexibility for emergent codes
- Reliability checking optional but recommended
- Structured process

**Workflow:**
1. Subset of team codes initial 5 transcripts independently
2. Meet to develop draft codebook
3. Test codebook on next 5 transcripts
4. Refine codebook based on testing
5. Divide remaining transcripts among coders
6. Regular calibration meetings
7. Calculate inter-rater reliability on subset
8. Group codes into themes collectively

**Time estimate:** 4-6 weeks

**Tools:**
- Dedoose (collaboration)
- NVivo or MAXQDA
- Shared codebook document

---

## Scenario 3: Policy/Applied Research (Tight Deadlines)

### Recommended Approach: Coding Reliability Thematic Analysis

**Characteristics:**
- Fixed codebook from literature
- High inter-rater reliability required
- Structured, efficient process
- Replicability emphasized

**Workflow:**
1. Develop codebook from literature/research questions
2. Intensive coder training (4-6 hours)
3. Practice coding with feedback
4. Independent coding with reliability checks
5. Resolve discrepancies through discussion
6. Theme generation from coded data

**Time estimate:** 2-3 weeks (accelerated)

**Tools:**
- Dedoose or NVivo
- Detailed codebook with examples
- Reliability calculator

---

## Scenario 4: Exploratory Research (Unknown Phenomenon)

### Recommended Approach: Inductive Reflexive TA

**Characteristics:**
- Bottom-up coding
- No preconceived framework
- Rich description prioritized
- Theory generation focus

**Workflow:**
1. Immersive familiarization
2. Line-by-line open coding
3. In vivo coding for participant language
4. Constant comparison throughout
5. Pattern coding for theme development
6. Theory building from themes

**Time estimate:** 4-6 weeks

**Tools:**
- QualCoder or Taguette
- Memoing software
- Concept mapping tools

---

## Scenario 5: Theory Testing (Existing Framework)

### Recommended Approach: Deductive Codebook TA

**Characteristics:**
- Top-down coding from theory
- Predefined codes
- Theory validation focus
- Mixed methods possible

**Workflow:**
1. Map theoretical constructs to codes
2. Create detailed codebook
3. Code data against framework
4. Note mismatches and extensions
5. Report fit and gaps in theory

**Time estimate:** 3-4 weeks

**Tools:**
- Structured codebook
- NVivo or MAXQDA
- Theory mapping diagrams

---

## Scenario 6: Multi-Language Data

### Recommended Approach: Reflexive TA with Translation Protocol

**Characteristics:**
- Translation as interpretive act
- Cultural context central
- Bilingual analysts preferred

**Workflow:**
1. Professional translation of key excerpts
2. Back-translation verification
3. Coding in original language where possible
4. Cultural consultants for interpretation
5. Explicit documentation of translation decisions

**Time estimate:** +50% time for translation

**Tools:**
- Professional translation services
- Bilingual codebook
- Translation decision log

---

## Scenario 7: Longitudinal Data (Multiple Time Points)

### Recommended Approach: Longitudinal Reflexive TA

**Characteristics:**
- Change and process focus
- Temporal analysis
- Within-case and across-case patterns

**Workflow:**
1. Code each time point separately
2. Create case summaries per participant
3. Analyze change within cases
4. Identify patterns across cases over time
5. Develop temporal themes

**Time estimate:** 6-8 weeks

**Tools:**
- Time-ordered matrices
- Case dynamics displays
- Process coding emphasis

---

## Scenario 8: Sensitive Topics (Trauma, Grief, etc.)

### Recommended Approach: Trauma-Informed Reflexive TA

**Characteristics:**
- Researcher self-care essential
- Ethical representation prioritized
- Reflexivity heightened

**Workflow:**
1. Researcher preparation and self-care planning
2. Careful transcription (tone markers)
3. Coding with attention to silences and emotions
4. Regular debriefing
5. Member checking for sensitive interpretations
6. Careful anonymization

**Time estimate:** +30% time for self-care and reflection

**Tools:**
- Reflexivity journal
- Peer debriefing protocol
- Self-care plan

---

## Quick Decision Guide

| If you have... | And need... | Use approach... |
|----------------|-------------|-----------------|
| Small dataset, alone | Rich interpretation | Reflexive TA |
| Large dataset, team | Consistency | Codebook TA |
| Tight deadline, policy context | Efficiency | Coding Reliability TA |
| Unknown phenomenon | Exploration | Inductive Reflexive TA |
| Existing theory | Validation | Deductive Codebook TA |
| Multiple languages | Cultural accuracy | Reflexive + Translation |
| Multiple time points | Change analysis | Longitudinal TA |
| Sensitive content | Ethical rigor | Trauma-Informed TA |

## Hybrid Approaches

Many projects benefit from combining approaches:

### Inductive-Deductive Hybrid
1. Start with literature-based codes
2. Allow emergent codes to be added
3. Final codebook contains both

### Individual-Team Hybrid
1. Lead researcher does initial coding
2. Team reviews and refines
3. Multiple coders on subset for reliability

### Semantic-Latent Hybrid
1. Begin with semantic (explicit) coding
2. Add latent (interpretive) level
3. Both levels feed into themes
