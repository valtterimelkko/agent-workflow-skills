# Interview Data Analysis Considerations

Specific guidance for conducting thematic analysis on interview transcripts.

## Transcription Preparation

### Transcription Styles

| Style | Use When | Characteristics |
|-------|----------|-----------------|
| **Intelligent Verbatim** | Most qualitative research | Removes fillers, false starts; preserves meaning |
| **Full Verbatim** | Conversation analysis | Every utterance captured |
| **Jefferson System** | Detailed interaction analysis | Captures pauses, overlaps, intonation |

### Pre-Coding Cleanse

1. **Initial review** - Check completeness against recordings
2. **Identify key sections** - Mark significant themes during first pass
3. **Remove irrelevant data** - Off-topic conversations, repetitive statements
4. **Edit for consistency** - Standardize terminology, formatting
5. **Preserve voice** - Correct spelling while keeping expressions

### Jefferson Transcription Notation

| Symbol | Meaning |
|--------|---------|
| [text] | Overlapping talk |
| (.) | Brief pause (0.08-0.2s) |
| (1.4) | Timed pause in seconds |
| underlining | Emphasis |
| wo::rd | Prolonged sound |
| ↑word / ↓word | Marked pitch shift |
| WORD | Louder speech |
| °word° | Quieter speech |
| .hhh / hhh | Inbreath / outbreath |
| ((comment)) | Analyst comments |

## Handling Interviewer Speech

### Approaches

| Approach | When to Use | How to Code |
|----------|-------------|-------------|
| **Exclude** | Standard thematic analysis | Code only participant responses |
| **Separate code** | Studying interview interaction | Use distinct "Interviewer" code |
| **Include** | Co-construction analysis | Code both as part of meaning-making |

### Considerations

- Language in interviews is socially constructed between interviewer and participant
- Document how follow-up questions shaped responses
- Note when interviewer clarifications changed direction
- Consider power dynamics in the interview relationship

## Individual vs. Group Interviews

### Individual Interviews (IDIs)

**Characteristics:**
- Personal narratives and individual perspectives
- Deep exploration of personal experience
- Response independence assumed
- Better for sensitive topics

**Analysis approach:**
- Within-case analysis first
- Treat each transcript as independent unit
- Look for individual narrative arcs

### Focus Groups (FGs)

**Characteristics:**
- Leverage group dynamics
- Response independence CANNOT be assumed
- Group is the unit of analysis
- Interaction data is as important as content

**Analysis considerations:**
- Analyze sequences of interaction (adjacency pairs)
- Note group dynamics and consensus-building
- Include nonverbal cues from video
- Capture interaction patterns in transcription

## Contextual Considerations

### Paralinguistic Features

Document when relevant:
- **Pauses** - Hesitation, thoughtfulness, discomfort
- **Tone changes** - Emphasis, emotional state
- **Speech rate** - Nervousness, excitement
- **Laughter, sighs, breath** - Emotional context
- **Interruptions** - Power dynamics

### Non-Verbal Data

When analyzing video:
- Facial expressions
- Gestures and body language
- Eye contact patterns
- Physical positioning

## Cross-Case Analysis

### Approaches

1. **Within-case first** - Understand each account completely
2. **Constant comparison** - Compare data segments throughout
3. **Matrix displays** - Use tables to compare across participants

### Pattern Identification

- Similarity: Things happening the same way
- Difference: Predictably different occurrences
- Frequency: How often something occurs
- Sequence: Order of events
- Correspondence: Relationships between activities

## Handling Sensitive Content

### Trauma-Informed Principles

1. **Safety** - Create secure environments
2. **Trustworthiness** - Build transparent relationships
3. **Choice** - Empower participant control
4. **Collaboration** - Share power
5. **Empowerment** - Support strengths

### Researcher Self-Care

- Acknowledge vicarious trauma
- Build self-care into process
- Use peer debriefing
- Take breaks from emotional content

## Working with Translated Data

### Key Decisions

| Option | Best For | Considerations |
|--------|----------|----------------|
| Full translation | Complete analysis | Most resource-intensive |
| Partial translation | Selective analysis | Balance fidelity and practicality |
| AI + human review | Efficiency with nuance | AI for draft, human for refinement |

### Quality Strategies

1. Use translators familiar with subject matter
2. Consider back-translation for verification
3. Include translators in analytic discussions
4. Document translation process explicitly
5. Report limitations and decisions made

### AI Translation Cautions

- AI struggles with idioms, emotion, implicit meaning
- Interview characteristics (dialect, jargon, informal speech) challenge AI
- Always human-review AI translations
- Risk of "over-translation"

## Ethical Considerations

### Anonymization

- Remove or pseudonymize identifying details
- Consider context that could identify participants
- Be extra vigilant with sensitive topics
- Maintain key to pseudonyms securely

### Member Checking

Types:
- Transcript review - Accuracy of representation
- Category check - Emergent understanding
- Interpretation review - Meaning-making validation
- Report review - Faithful representation

Best practices:
- Present in accessible formats
- Frame as "Does this resonate?" not "Is this correct?"
- Document all feedback
- Be transparent about disagreements
